# يومي — جدول المهام اليومية والتدوين

تطبيق أندرويد مبني بـ Flutter، يعمل دون إنترنت، ويحفظ بياناته في قاعدة SQLite على الهاتف.

## الميزات

- **قائمة يومية تلقائية**: في أول فتح للتطبيق كل يوم تُنشأ مهام الروتين تلقائياً (ورد القرآن والتجويد، أكاديمية زاد، مواد GED، البحث عن عمل، الأذكار والقراءة/الرياضة). يكتشف التطبيق بداية اليوم الجديد حتى لو بقي مفتوحاً بعد منتصف الليل.
- **إدارة المهام**: إضافة مهمة لليوم فقط أو إضافتها للروتين لتتكرر، وتعديل وحذف، وعلامة إنجاز، وشريط تقدم بنسبة الإنجاز.
- **الروتين اليومي** (من الإعدادات): إضافة وتعديل وحذف وإعادة ترتيب المهام الثابتة بالسحب. التعديلات تسري من اليوم التالي.
- **التدوين**: ما أُنجز، العقبات، الأفكار، وتقييم اليوم بالنجوم. الحفظ تلقائي أثناء الكتابة.
- **الأرشيف**: تقويم شهري ملوّن حسب نسبة الإنجاز، وإحصاءات الشهر، وقائمة بالأيام المسجّلة. الضغط على أي يوم يعرض مهامه وتدوينته.
- **المظهر**: عربي بالكامل (من اليمين لليسار)، ووضع فاتح/داكن/تلقائي.

## الطريقة الأولى: البناء من الهاتف عبر GitHub (دون حاسوب)

1. أنشئ مستودعاً **خاصاً (Private)** جديداً في GitHub.
2. ارفع محتويات هذا المجلد كما هي إلى الفرع `main` (مع مجلدي `.github` و`signing`).
3. يبدأ البناء تلقائياً. تابع التقدم من تبويب **Actions** (يستغرق نحو 5–10 دقائق).
4. عند انتهائه افتح **Releases** في صفحة المستودع، ونزّل ملف `yawmi-1.0.X.apk`.
5. افتح الملف من الهاتف ← اسمح بـ «تثبيت التطبيقات من مصادر غير معروفة» للمتصفح أو مدير الملفات ← تثبيت.

لإعادة البناء يدوياً: Actions ← Build APK ← Run workflow.

## الطريقة الثانية: البناء على حاسوب

1. ثبّت [Flutter](https://docs.flutter.dev/get-started/install) (الإصدار 3.47 أو أحدث) و[Android Studio](https://developer.android.com/studio) (لتنزيل Android SDK)، ثم شغّل:
   ```bash
   flutter doctor --android-licenses
   flutter doctor
   ```
   وتأكد أن سطري Flutter وAndroid toolchain بعلامة ✓.
2. داخل مجلد المشروع، أنشئ ملفات أندرويد الناقصة (لا يمس ملفات `lib/`):
   ```bash
   flutter create . --project-name yawmi --org com.hassan --platforms android
   ```
3. (اختياري) غيّر اسم التطبيق إلى «يومي» في `android/app/src/main/AndroidManifest.xml`: `android:label="يومي"`.
4. (اختياري، لتطابق توقيع بنايات GitHub) انسخ `signing/yawmi-signing.keystore` إلى `~/.android/debug.keystore`.
5. ابنِ الملف:
   ```bash
   flutter pub get
   flutter build apk --release
   ```
   الناتج: `build/app/outputs/flutter-apk/app-release.apk`
6. انقله إلى الهاتف وثبّته، أو صِل الهاتف بكابل USB مع تفعيل «تصحيح USB» ثم: `flutter install`.

## ملاحظات مهمة

- **التحديثات دون فقدان البيانات**: أندرويد يرفض تثبيت نسخة جديدة فوق القديمة إذا اختلف مفتاح التوقيع، وحينها يجب حذف التطبيق فتضيع بياناته. لذلك يستخدم مسار GitHub مفتاحاً ثابتاً من مجلد `signing/`. أبقِ المستودع **خاصاً**، ولا تخلط بين نسخ مبنية بمفاتيح مختلفة.
- هذا المفتاح مناسب للاستخدام الشخصي. للنشر في Google Play أنشئ مفتاح رفع خاصاً بك.
- البيانات محلية فقط. النسخ الاحتياطي التلقائي في أندرويد (Google) يشمل قاعدة البيانات عادةً إن كان مفعّلاً في هاتفك.
- لتغيير بنية الجداول مستقبلاً: ارفع `_dbVersion` في `database_helper.dart` وأضف خطوة الترقية في `_onUpgrade`.
